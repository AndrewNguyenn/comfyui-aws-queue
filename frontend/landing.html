ComfyUI AWS Queue

Personal ComfyUI deployment with spot-based GPU workers, queue-driven jobs, and image+video fleet specialization.

Pages

  • Sign in — Cognito-authenticated entry point
  • Models — paste CivitAI URLs, browse the model catalog
  • Outputs viewer — view generated images and videos by job ID

Status

v1: standalone pages only. The vanilla ComfyUI workflow editor moved to a separate Comfy-Org repo and no longer ships a pre-built dist; full editor integration is deferred to v2. Submit workflow JSON manually to POST /prompt for now.
